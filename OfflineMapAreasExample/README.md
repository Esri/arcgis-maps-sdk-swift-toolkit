# OfflineMapAreas Example App

This is an application that shows how to use the Offline Map Areas toolkit component.

Documentation for the Offline Map Areas toolkit component is [here](https://developers.arcgis.com/swift/toolkit-api-reference/documentation/arcgistoolkit/offlinemapareas).

## Instructions

 1. Clone or download this repo
 2. Open the `OfflineMapAreas` project in Xcode by double clicking on the `OfflineMapAreasExample.xcodeproj` file
 3. Build and run the project
